KuroCubeRacing 🎮
DIY sim racing peripherals built around the RP2040-Zero microcontroller.
Current hardware

Pedals — throttle and clutch via SS49E Hall effect sensors, brake via HX711 load cell (in progress)
H-Shifter — 6-position shifter using 4 limit switches on RP2040-Zero
Interface — USB HID gamepad, no drivers needed

Stack

RP2040-Zero
Adafruit TinyUSB
HX711 library
