KuroCubeRacing 🎮
DIY периферия для симрейсинга на базе микроконтроллера RP2040-Zero.
Железо

Педали — газ и сцепление на датчиках Холла SS49E, тормоз на тензодатчике с HX711 (в процессе)
H-коробка — 6 позиций на 4 концевиках, RP2040-Zero
Интерфейс — USB HID геймпад, драйверы не нужны

Стек

RP2040-Zero
Adafruit TinyUSB
HX711 library
